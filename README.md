# Propostas Bendita Viagem

Catálogo estático das propostas da Bendita Viagem.

## Organização

- `index.html`: catálogo de propostas.
- `punta-cana-27nov-05dez-2026/index.html`: proposta de Punta Cana.
- `punta-cana-27nov-05dez-2026/assets/images/`: imagens locais da proposta.

Cada proposta deve ser totalmente independente, com HTML, estilos, scripts e imagens dentro de sua própria pasta. Use caminhos relativos. Não compartilhe assets entre propostas e não use hotlinks.

## Publicação

Sirva a raiz como site estático, sem comando de build. O catálogo abre cada proposta pela pasta correspondente.

## Adicionar propostas

1. Crie uma pasta com nome do destino e datas.
2. Inclua `index.html` e `assets/images/` com os arquivos locais.
3. Adicione um link no catálogo da raiz.
4. Verifique textos, valores, validade e caminhos antes de publicar.
